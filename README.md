# بنك أسئلة TIMSS

مدرسة الدراز الإعدادية للبنات — مبادرة من قسم التمكين الرقمي في التعليم.
فكرة وإعداد: اختصاصية تكنولوجيا التعليم أ. زهراء فلاح — العام الدراسي 2026–2027.

بنك أسئلة العلوم والرياضيات للصفين السابع والثامن مع نماذج الإجابة وأسئلة مقترحة.

- `index.html`: الصفحة.
- `data/`: الأسئلة (`sci7`, `sci8`, `math7`, `math8`) والأسئلة المقترحة (`similar.json`).
- الإحصائيات عبر GoatCounter.
